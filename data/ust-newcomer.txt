香港科技大学（HKUST）新生指南信息整理（详细版）
========================================

一、学校概况
------------
1. 香港科技大学创立于1991年，主校区位于香港西贡区清水湾半岛，依山傍海而建，景色很好。
2. 图书馆后方海边步道、李兆基大楼天台可看海；不足之处是学校位置较远。
3. 科大官方校训：“求新，求进，求未来”。

二、入学前准备与Offer处理
--------------------------
1. 收到 conditional offer（con-offer）后，火速登录 HKUST Application Portal 上传：
   - 学位证
   - 毕业证
   - 官方成绩单（需学校密封信封/公证）
   - 推荐同步提交学信网认证
   - 逾期可能直接撤回名额
2. 拿到 conditional offer 后，需上传学校要求的文件换取 firm offer：
   - 学位证书
   - 大学成绩单
   - 语言成绩等
3. 一定要在截止日期（ddl）前接收 offer，以免影响入学资格。
4. 及时查收并注册学生账号和学校账号，以便获取重要通知。
5. 完成新生注册任务，如上传学生证件照等。
6. 每学期开始前缴纳学费；新生需缴纳押金，作为图书馆扣费或其他费用的预付款。

三、开学必办证件与卡（四卡一证）
--------------------------------
开学必办：四卡一证
1. 学生卡
2. 八达通卡
3. 电话卡
4. 银行卡
5. 身份证

具体说明：
1. 学生卡：提交课程注册所需所有文件，包括身份证明文件、在香港就读的相关签证、签证入境标签及学生卡证件照。
2. 身份证：抵港后30天内登记并领取居民身份证，需先预约，之后前往线下办理，大概7个工作日可拿到。
3. 八达通：香港生活必备，学生可享受八达通交通优惠，可办理虚拟卡或实体卡。
4. 学生签证：现在发放电子签（e-visa），不易丢失。准备相关纸质材料邮寄到学校提供的地址，并通过学校支付办理学生签费用；部分学校支持在线提交材料，之后可获得学生签以及不反对信（NOL）。
5. 港澳通行证：可在本地的县级以上公安机关出入境管理部门申请办理，预约时间携带办理材料到申请网点办理。
6. 逗留签（D签）：在逗留签有效期内可无限次往返香港与内地城市；需在拿到香港学生签之后再办理，预约时间携带办理材料到申请网点，约15天可拿到。
7. 出门随身携带 HKID，临时的也行，否则可能被阿sir罚。
8. 提前预约办理，否则会很麻烦（攻略和办理步骤见新生小册子）。

四、交通与地理位置
------------------
1. 没有地铁可以直达科大。
2. 科大学生主要依靠小巴：
   - 北门小巴 11M 去坑口
   - 南门小巴 11 去彩虹
   -大巴91，91m
3. 距离最近的地铁站有坑口和宝琳。
4. 将军澳是富人区，离科大不算远（也不近）。
5. 到达香港可选择：
   - 香港国际机场
   - 高铁到香港西九龙站
6. 交通上使用学生八达通坐91M巴士能半价，往返地铁站的接驳巴士不要费用。

五、住宿与租房
--------------
1. 科大宿舍有很多栋。
2. 本科生前两年基本可以保宿，后面不一定。
3. TPG（授课型研究生）基本无宿舍。
4. 本科生宿舍避雷五号宿舍（来自新生组织里一位老学姐的忠告）。
5. 如果不想住校，离学校最近的租房区域是大埔仔，走到科大北门十分钟左右，房租相对其他地区较便宜。
6. 校外合租（如大埔仔村）一般比宿舍便宜，人均约4500港币左右。
7. 签合同前记得找学生会法律顾问（无需费用）帮看一遍，避坑。

六、选课（SIS系统）
-------------------
本科生在 SIS 完成选课，主要分为三个阶段：
1. Validation Period（Shopping Cart Appointment）
   - 搜索课程信息，规划课程安排
   - 将想要选择的课程添加到 Shopping Cart
2. Enrollment Period（Enrollment Appointment）
   - 在固定时间段内选课
   - 确认提交 Shopping Cart 的课程并注册课程
3. Add / Drop Period（Open Enrollment）
   - 可以添加或者退掉课程，更改自己的选课

选课时间线（26Fall 参考）：
1. 港科大26Fall本科新生选课：
   - Shopping Cart / Validation：8月21日
   - 研究生新生选课：8月25日
   - 本科生 Year1 选课：8月26日
   - Add/Drop Period：9月1日—14日
2. 本科生每个人都有自己的 Enrollment Appointment，具体开始时间要去 SIS → Student Center → Enrollment Dates 查看。
3. 研究生完成 Programme Registration、激活学生账号后，即可通过 SIS 选课，每个专业选课时间由学院通知。

选课操作建议：
1. 正式选课前熟悉 SIS 操作：
   - 先想选的 Course 放进 Shopping Cart
   - 再用 Validate 检查是否满足选课条件
   - 到了自己的 Enrollment Appointment，再重新进入 SIS 正式提交选课申请
2. 先确认 Pre-enrolled 课程，再制定选课计划：
   - 登录 SIS 后先看学校有没有已经帮你 Pre-enroll 课程
   - 这类课程已经属于 Confirmed Enrollment，不需要再放进 Shopping Cart 重新选
   - 必修课不建议随便 Drop，需要特殊理由时还可能要申请 Approval
3. 多准备两套备选课程：
   - 每门想选的课最好提前准备1—2个 Plan B
   - 可用 Timetable Planner + Class Schedule & Quota 提前排时间、看 Section 和剩余名额
   - 满课后可加入候补；想换课时考虑用 Swap，原课程不会在新课程成功加入前被直接 Drop
4. 选完后重新检查课表：
   - Submit 成功后，再回 SIS 检查 Class Schedule 和 Enrollment 状态
   - 确认 Course、Section 和上课时间都正确
   - 如果课程满了进入 Waitlist，记得关注 Waitlist 状态
   - Add/Drop 期间还可以继续调整，但9月14日后原则上不能再随意 Add/Drop

七、教材购买
------------
1. 每年春季和秋季学期开始时，教科书供应商将安排并运营一个临时校园教科书服务点，为期3至4周。
2. 可通过网上教科书服务系统购买教材。
3. 买二手书或电子书更划算，可以找学长学姐或蹲二手。

八、校园餐饮与省钱技巧
----------------------
1. LG1 Canteen 是美心，烧鸭腿饭 + 冻柠茶还不错。
2. LG5 的麦当劳，考试周通宵营业。
3. LSK 食堂可试试卷饼（还可以，但别报太多希望，HK 无美食）。
4. LG7 食堂有隐藏菜单：直接说“科大全餐”，两菜 + 饭 + 饮料才38港币，比分着点划算。
5. 校内百佳超市晚上8点后面包、沙拉经常打折，带上学生证买饮品也可能有优惠。
6. 校外坑口村的大排档，用学生证点干炒牛河，老板有时会送冻柠茶。

九、校园设施、自习地点与隐藏福地
--------------------------------
1. 主图书馆24小时自习区在 G 层，插座多但冷气像冰窖。
2. 顶楼海景座位需早8点抢。
3. LSK 自习室人少安静，Wi-Fi 速度全校最快。
4. 商学院郑裕彤楼里面靠海的位置视野超好，还配有彭博终端。
5. 工学院 E2 楼有个电脑室通宵开放，不用预约就能进去。
6. 如果入选“本科生研究机会计划”，还能拿到实验室24小时门禁，自习时间自由很多。
7. 体育馆游泳池只需要预约就可以 FREE 使用，超级划算。

十、学生优惠与福利
------------------
1. 别错过学校的学生专属 discount 和一些福利。
2. Su store 学生9折。
3. G 层书店有学生优惠。
4. 体育馆游泳池预约即可免费使用。
5. 别忘了用学校邮箱激活 Microsoft365 和 MATLAB，正版软件不用白不用。
6. 科大纪念品超绝，不仅有文创还有教授们的各类科研成果衍生品，比如蜂蜜。

十一、职业发展、实习与奖学金
----------------------------
1. 别错过 Career Center，有 LinkedIn Premium 资格，还有一些大厂内推（鹅厂、高盛之类的）。
2. 科大和很多大企业有独立招聘合作，校友内推机会不少。
3. 金融圈一些顶尖公司会特别留意学院排名靠前的学生，校友网强。
4. 校内有不少薪资不错的岗位，比如计算机系助教、图书馆 IT 助理。
5. 校外也可以接一些数据分析的活儿，或者申请中环金融公司的实习，时薪挺可观。
6. 理工科：学校和腾讯、大疆等公司有内推通道，教授也常推学生去商汤科技这类实验室。
7. 商科：可以参加汇丰的大湾区培训生计划，学校还提供高盛交易系统的模拟账号给学生练手。
8. 环境科学：有和香港环保署合作的项目，奖学金给得大方，实验室也可能直接推实习。
9. 学校奖学金丰富，包括 University Admissions Scholarship Scheme、Mainland JEE TopScorers Scheme 等，可以努力争取。

十二、生活小贴士
----------------
1. 香港台风天多，最好在学生会便利店买把扎实的折叠伞。
2. 宿舍允许用小冰箱，日本城有符合尺寸的，不贵。
3. 科大有一位必须要认识的最重要的老学长：野猪学长（字面意义上的），多次出现在校园文创产品，经常回访母校。
4. 如果有25/26的校历壁纸，可以比别人更快 get 假期规划。
5. 校历壁纸可参考另一篇 UST 校历壁纸笔记。

十三、必备 APP
--------------
1. Canvas
   - 科大学习核心工具
   - 课程安排、作业提交、考试信息都在这里
   - 新生一定要开启消息通知，避免错过重要截止日期

2. Duo Mobile
   - ITSC 账号双重认证神器
   - 登录时基本都需要用它验证，保障账号安全
   - 可理解为“科大版 Steam 令牌”

3. HKUST Student
   - 科大官方全能 APP
   - 查考试时间、看成绩（CGA、TGA）、充值电子钱包、订体育场、找教室路线等

4. USTing
   - 科大学生自主研发的实用工具
   - 功能不如 HKUST Student 多，但设计更贴心
   - 可查课表、订图书馆小房间、预约体育设施
   - 宿舍同学还可查看 Laundry Service

5. HKUST iLearn
   - 科大官方开发 APP，主要有三个功能，可跳转至相应软件或网站：
     - Canvas：课程管理
     - SFQ：Student Feedback Questionnaire，期末课程评价
     - iPRS：在线答题模块，用于回答堂上问题或小测，方便教授记录出勤

6. Path Advisor
   - 科大版电子地图
   - 可查各个教室、大楼、餐厅
   - 输入目的地可指导路线，但有些地点可能不够准确
   - 也可查看实时公交车站排队情况，类似高德
